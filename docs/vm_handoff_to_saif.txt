HOW TO SCORE
------------
Full step-by-step checklist: docs/vm_scoring_task_saif.md
The frozen model files are not in this checkout. Place these in results/models/:
  - preprocessor.joblib
  - xgboost_baseline.joblib
Then run from the repository root:

  python src/score_vm.py --adapted data/processed/vm_adapted.parquet --out-dir results

Expected outputs:
  - results/vm_predictions.csv
  - results/vm_scenario_summary.csv
  - results/vm_summary.json

The runner uses the validation-selected XGBoost threshold 0.55 and the frozen
rule engine as an external hybrid check. It will refuse to run without the
adapted file and will not fabricate numbers.
