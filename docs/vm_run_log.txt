What failed or was skipped (and why)
  - ATT-1197 (T1197, BITS local transfer) FAILED and is excluded from the clean
    dataset and from scoring. `Start-BitsTransfer -Source C:\Lab\source.txt
    -Destination C:\Lab\bits_copy.txt` returned:
      "There are currently no active network connections. Background Intelligent
       Transfer Service (BITS) will try again when an adapter is connected."
    The two Event ID 1 rows captured in its window were the powershell.exe wrapper
    and Windows Defender NisSrv.exe, not a BITS transfer, so they are not a valid
    T1197 observation.
  - T1548.002 (UAC bypass) was intentionally not run. A genuine bypass needs an
    HKCU\Software\Classes\ms-settings hijack, which is a security-control bypass
    and close to the "no persistence" line. The written scope does not explicitly
    name UAC bypass, so it is recorded as not feasible / out of scope.
  - T1569.002 (PsExec-style service execution) was not run. PsExec is not
    installed, and creating a service modifies the system, outside the harmless
    scope.
  - T1105 (certutil urlcache download) was not run. `certutil -urlcache` needs an
    HTTP endpoint and the VM had no network access during attack simulations.
  - First attempt at ATT-1218-007 failed with "The term 'A' is not recognized"
    because the short alias had not been defined yet. No scenario was started and
    the run was repeated successfully.
  - During ATT-1059-001 the main PowerShell window closed and was reopened
    non-elevated. Sysmon log access needs elevation, so it was reopened as
    Administrator and the helper re-sourced. `Test-Path C:\Lab\out\
    current_scenario.json` returned False, so ATT-1059-001 had already exported;
    it was not re-run.
